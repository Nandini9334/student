About this application

This student record application demonstrates a Python Flask web application deployed through a DevOps CI/CD workflow.

Technology stack

  • Python and Flask — web application
  • Git and GitHub — source control
  • Docker — container image
  • Kubernetes — deployment and service
  • Jenkins — continuous integration and deployment

Storage note: This lab version uses in-memory storage. Student records reset when the application process restarts, and different Kubernetes replicas may have different records.
